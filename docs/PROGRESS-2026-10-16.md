# Goldmember: progress report, 2026-10-15/16

A page-by-page audit of the whole site (72 customer pages and 220 admin pages, crawled with a
headless browser), followed by four sprints of fixes. Each sprint is a local git branch, and each
branch builds on the one before it:

```
main ─▶ sprint-1-security ─▶ sprint-2-broken-pages ─▶ sprint-3-data-ops ─▶ sprint-4-seo-i18n-perf ─▶ sprint-5-cleanup
```

**Status:** 15 commits (sprint 5 added on 2026-10-16). All 49 Playwright tests pass, plus 1 skipped; that includes a new smoke
test that checks every page. **Nothing is merged into `main`, pushed or deployed yet.** See
[What's left](#whats-left) and the [deploy checklist](#production-deploy-checklist).

---

## What was done

### Sprint 1: Security (`sprint-1-security`)
| Problem | Fix |
|---|---|
| **Any registered customer could log into the admin panel** and open Users Management. LoginForm never checked the role, `CAccessRule` treated "admin" as "any logged-in user", and 29 of 46 admin controllers had no access rules at all. | `backend/components/AdminAccessControl` is a single gate for the whole admin app, attached from the tracked `backend/config/bootstrap.php`. Guests are sent to the login page; AJAX requests get a 403 so the login page doesn't fall into a reload loop. Admins can reach everything, brokers only the product section, and customer sessions are logged out. The admin LoginForm rejects customers with the same message as a wrong password. |
| Admin translation endpoints (`tr-*/update`) needed no login. | Covered by the gate. |
| Gii (code generator) and the debug module were enabled with `allowedIPs '*'` outside dev (`backend/config/main-local.php`). | Admin-only through the gate. Fixed locally; **production needs a manual fix** (the file is gitignored). |
| An expired APNS certificate with its **private key** was committed in `common/config/apnscert/`. | Removed. It's still in git history. |
| A dead GitHub token was embedded in the git remote URL. | Removed from the URL. |
| (none) | Regression tests: `test_backend_access_control.py`. |

### Sprint 2: Broken pages (`sprint-2-broken-pages`)
**Security holes found while working through the broken pages:**
- `site/login-user` ("social login") **logged the caller in as any user whose email they posted**, with no provider token check. I confirmed this locally, and removed the endpoint; no page used it.
- The frontend blog allowed **public create, update and delete**, with delete working over GET. Blog URLs now 301 to `/news`.
- Customer address edit and delete worked on **any user's address**. They're now scoped to the user's own addresses.
- A public product "rate" endpoint let anyone overwrite ratings. Removed.

**Customer site:**
- The profile crashed for users without a customer record, and History and Change password crashed for everyone (`User::CUSTOMER` was never defined).
- Change password compared "confirm" against the *old* password, and the page had no submit button. It's rebuilt and linked from the profile.
- The news ticker had relative links (`/am/news/am/news/17`), and the homepage "Show more" linked to a 404.
- The footer showed Lorem ipsum, its links were all `#`, and it printed a hardcoded wrong phone number. Phone and email now come from site settings everywhere.
- The homepage map link pointed to **San Francisco**.
- News category pages showed six fake lorem posts with broken images.
- `/contact` had a form that posted nowhere. It now redirects to the homepage contact section.
- Removed the dead code from a car-parts template, which returned 500s: Service, Faq, brands, cart view, search-by-vin.
- **The frontend wrote no error log**, because the `log` component wasn't bootstrapped.

**Admin:**
- Customer create and edit returned 405. Create also never rendered its form and left the user record without an email. Both are rebuilt with a transaction.
- Media (gallery and videos) returned 500 because of nonexistent columns. Gallery upload needs `files.title`/`link`, which the SQL update adds.
- Exchange pages crashed on undefined variables. They now redirect to Metal Prices.
- The CKEditor config set its plugins three times (only the last applied), used a Russian UI, loaded a cloud plugin without a token, and the Partners form initialised editors on news field ids.

### Sprint 3: Data and operations (`sprint-3-data-ops`)
- **Email was broken everywhere**, because Swiftmailer throws on PHP 8.2. The `common\components\Mailer` wrapper is registered through the DI container, and SMTP can be set with optional `SMTP_*` env vars.
- **Auctions close automatically** at their end time. The highest bidder is recorded, with an atomic update so it happens once, and gets a "You won" email. Admin "Finish Auction" sends the same email.
- **The homepage price tables were empty.** They only showed prices entered today, and Global Prices read whichever metal row came first. The **"Change" column was a hardcoded "↓ 0.3"** on every row. All three tables now show the latest data, with a real change and an "as of" date.
- `updateExchange.php` only runs from the CLI or cron, never over the web. The admin panel warns when prices are more than 48 hours old; on production they've been stale since 2026-05-22.
- `database/updates/` holds idempotent SQL files, including the bidding schema from May, which had been applied by hand.
- The local auction test no longer leaves a duplicate auction behind on every run.

### Sprint 4: SEO, i18n, performance, admin dashboard (`sprint-4-seo-i18n-perf`)
- **SEO:**
  - `lang="hy"`, the correct ISO code; it was always `en`.
  - A real meta description; before, description and keywords were swapped and both said "Goldmember", and the author was "John Doe". Articles and products now use their own description and image.
  - Open Graph and Twitter tags, a canonical link, hreflang alternates for `hy`, `en` and `x-default`.
  - `/sitemap.xml` and `robots.txt`.
- **Armenian:** 339 strings now in Armenian script. Before, 108 were Latin transliterations ("Achurdut", "Haytn ayn", "Մutkh"), some were leftover Russian, and about 180 had no Armenian at all.
- **Performance:**
  - The logo, shown at 32 px on every page, went from 439 KB to 39 KB.
  - The donate banner went from 2 MB to 77 KB.
  - Font preloads dropped from 11 files (about 1.2 MB) to 2.
  - Bootstrap Icons are self-hosted and pinned to 1.13.2; they had been loading from an unversioned CDN URL.
- **Admin dashboard** with KPIs: visitors, new customers, live and upcoming auctions, bids today, sold this month, donations, and the gold spot price.
- **Mobile homepage hero:** the bull and bear image fills the screen width on phones, the text is smaller, and the overlapping "Welcome" heading is fixed.
- **Smoke test** (`test_smoke_all_pages.py`) checks every public, account and admin page. It already caught one more bug: Metal Prices → Update.

### Sprint 5: Cleanup (`sprint-5-cleanup`, 2026-10-16)
- **Removed leftover files:** 19 `*-old*` and backup views and controllers (including `CartController-Old.php`), plus
  the car-parts category listing (`CategoryController`, `views/category/`, the `productLayout` and `top_menu` layouts).
  `/category/slug` used to return a 500.
- **Removed two more dead routes that returned 500s:** `/filter-product` (and its unused `site/filters.php` form) and
  `/user/profile-image` (an empty placeholder page with its own `profile` layout). Found by requesting every
  parameterless frontend action.
- **The admin font now renders Armenian.** Noto Sans Armenian is self-hosted (27 KB) and registered as extra
  `Open Sans` faces limited to the Armenian code range, so every existing rule picks it up. The browser downloads it
  only on pages that contain Armenian text.
- **Exchange rates:** the admin form now rejects a sell rate below the buy rate. The stored USD row (sell 382.68,
  buy 390) is still reversed, and the form makes you fix it the next time it's edited.
- **Debug toolbar 404 (local only):** `backend/runtime/debug/index.data` belonged to the host user, so Apache
  couldn't update it. Ownership is fixed and 540 MB of stale debug data was cleared. There was no code change.

### Local environment

- Local admin login: `admin` / `admin`.
- opcache `revalidate_freq` is set to 0 for development.
- The four auction columns missing from the local database were added.

## Production deploy checklist

1. **Back up** the production database and files.
2. **SQL in phpMyAdmin**, in this order (every file is safe to run twice):
   1. `database/updates/2026-05-24-bidding.sql` (probably already applied)
   2. `database/updates/2026-10-16-sprint-2.sql`
   3. `database/updates/2026-10-16-armenian-translations.sql`
   4. `database/updates/2026-10-16-sprint-5.sql`
3. **Upload and delete files** with `scripts/deploy-ftp.sh` (production runs commit `a80851e`, the May bidding deploy):
   ```bash
   scripts/deploy-ftp.sh a80851e main                    # dry run: prints the lftp plan
   FTP_PASS='...' scripts/deploy-ftp.sh a80851e main --go  # upload 59 files, delete 51, clear runtime caches, verify sizes
   ```
   It never touches `tests/`, `docker/`, `docs/`, `database/`, `.env`, `.htaccess`, `common/config/db-local.php` or the root
   `index.php`. The deletions matter: otherwise old insecure controllers such as `ServiceController.php` stay live.
4. **Optional data cleanup** in phpMyAdmin: `database/updates/2026-10-16-data-cleanup.sql` removes the junk news categories
   and the "asdfasdf" blog post (only rows still holding that junk text). The USD rate swap in it is commented out.
5. **Gitignored production files, edit by hand:**
   - `backend/config/main-local.php`: enable `debug`/`gii` only `if (YII_ENV_DEV)`, and remove `'allowedIPs' => ['*']`.
   - `frontend/web/index.php` and `backend/web/index.php`: `YII_DEBUG` false, `YII_ENV` `prod`.
   - `common/config/params.php`: `'adminUrl' => 'https://admin.goldmember.am/'`.
6. **Clear caches:** `frontend/runtime/cache/*` and `backend/runtime/cache/*`.
7. **cPanel cron** (daily): `php /home/gssamru/goldmember.am/updateExchange.php`.
8. **Smoke-test** https://goldmember.am/am, /en, /am/auction, /sitemap.xml, the profile and change password, and the admin login.
   Then log into admin.goldmember.am **with a customer account** and confirm it's rejected.
